A short poem about giving someone the power to close a door—and respecting it by knocking.

Entry for [The Poem About Permission](https://make.fun/bounty/the-poem-about-permission-20261121-0235).

Run with Python 3.13: `python3 -P -s main.py`. Uses only the standard library and writes the poem to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to choose another output directory.
